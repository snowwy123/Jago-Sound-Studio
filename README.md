# Jago Sound 0.10.0

Make a little noise. Or a whole song.

Compose editable music, invent sound effects and build ambience offline. Begin from a score, an example, a seeded idea or an empty composition and shape it yourself.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Sound-Studio/releases/latest)

## Get started

Download **Jago-Sound-v0.10.0.zip**, right-click it and choose **Extract All**. Open **Jago-Sound.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-Sound.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Sound-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Editable parts, note patterns, song sections, instruments and a visible mixer.
- Seeded complete-song approaches, feelings, arrangements, locks and alternatives.
- MIDI score import with supported full-score or passage choices.
- Sound Workshop combines editable tones, noise, impacts and recordings.
- Separate working-track and sound-recipe folders; native project backups.
- Ensemble-led generation adds an answering approach to the existing families.
- Natural phrasing, stronger accents and performance shaping vary note strength/articulation.
- Mix parts shows level, pan, mute/solo together; shape notes previews edits with Undo.
- Invent from ingredients adds mechanisms, clusters, pulses and evolving loops.
- Check loop join plays two consecutive copies; stereo transfers retain both channels.
- Give the melody room coordinates generated details; existing songs have an explicit undoable coordination action.
