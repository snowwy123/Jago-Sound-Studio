# Jago Sound 0.9.0

Make music, effects and ambience your way. Editable songs, seeded ideas and a sound workshop that starts from scratch.

This repository contains the application source, examples, licence notices and illustrated guide. See **DEVELOPING.md** to build it. Ready-to-use Windows downloads belong under GitHub Releases.

## Get started

Read **Documentation/Jago-Sound-Studio-Guide.pdf** for an illustrated introduction. The app’s **?** menu provides help and shortcuts. Start with a blank project or explore the editable examples. Save your editable project as well as any finished exports. Each studio works independently; Workscape is optional.

## Try online

[Open Jago Sound in your browser](https://snowwy123.github.io/Jago-Sound-Studio/). The root **index.html** is the current self-contained browser build. GitHub Pages should publish from **main / (root)**; **.nojekyll** keeps it a plain static site.
